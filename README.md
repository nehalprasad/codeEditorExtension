# luminosKnowHemingway

## Overview
luminosKnowHemingway is a Visual Studio Code extension designed to enhance your writing experience by providing insights and suggestions based on the principles of Hemingway's writing style. This extension aims to help users write clear, concise, and impactful prose.

## Features
- Analyze your text for readability and clarity.
- Provide suggestions to simplify complex sentences.
- Highlight passive voice usage and suggest alternatives.
- Offer insights on sentence length and structure.

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/luminosKnowHemingway.git
   ```
2. Navigate to the extension directory:
   ```
   cd luminosKnowHemingway
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Open the project in Visual Studio Code.

## Usage
1. Open a text file in the editor.
2. Activate the extension by running the command `Hemingway: Analyze Text` from the command palette (Ctrl+Shift+P).
3. Review the suggestions provided in the output panel.
